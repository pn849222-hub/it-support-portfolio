# pn849222-hub.github.io

Personal page of Nguyễn Vũ Trường Phúc (Ben), a backend and data developer in Ho Chi Minh
City and co-founder of VANG LAI.

Live at https://pn849222-hub.github.io/

## What's here

- `index.html`, `styles.css`: one static page, no build step.
- `motion.js`: about 50 lines of plain JavaScript that turn scroll position into a `--p` value
  from 0 to 1 for each `[data-scroll]` section. The CSS reads it to pin the pipeline story and
  slide the projects sideways. With reduced motion every section shows its finished state; without
  JavaScript the page reads top to bottom.
- `assets/`: the photo (two-tone), a chart from the job-market project, a Swagger screenshot of
  the job-market API, and a screenshot of VANG LAI running locally on demo data.
- `Nguyen-Vu-Truong-Phuc-CV.pdf`: the one-page CV.

## Editing

Change the text in `index.html` and update the date in the footer. Images are WebP, sized for
a 2x display.
