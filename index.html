Catch

Each page carries a JSON-LD block for search engines. This one says USD. Its own text says dong.

24 of the 183 published salaries had the same problem.

"baseSalary": {
  "@type": "MonetaryAmount",
  "currency": "USD",
  "value": {
    "@type": "QuantitativeValue",
    "unitText": "MONTH",
    "value": "14 – 16 million VND/month"
  }
}

Clean

My pipeline reads the currency from the text and converts dong at 26,300 to the dollar.

Read as dollars, this posting would have counted as $14 to $16 a month.

# before
currency         "USD"
value            "14 – 16 million VND/month"

# after
salary_currency  "VND"
salary_min_usd   532.32
salary_max_usd   608.37

# 14,000,000 / 26,300 = 532.32
# 16,000,000 / 26,300 = 608.37
